# /demo/ — the presentation demo (notes for Claude)

Built 24 Oct 2026 for Jan Erik's talks on technology in education: one course,
front and back. Read the root `CLAUDE.md` first.

- **`index.html`** — the landing page: what the student sees, what the instructor
  sees, the two things built for the talk (feedback board, final exam), an
  8-minute run sheet, the site's ideas and which ones this demo shows.
- **`course/`** — a copy of `SUMAS/ombafr455` (minus `_private`, `admin.html`)
  with `data-course="demo"`: its own namespace `demo` (courses.json, the
  config.js mirror and a rules block copied from ombafr455's — **deploy the
  rules** or sign-in and messages on the copy say "refused"). Plus
  `feedback.html`: four 1–5 ratings + two sentences a week, hidden inputs with
  `data-work` (`fb_wN_clear|pace|work|useful|helped|change`), module `feedback`.
  The hub carries a "Demonstration copy" note and a feedback card. ⚠ Do not
  edit the course pages here for content — fix the real course and re-copy.
- **`admin.html`** — the back end, SELF-CONTAINED: reads `data.js`, never the
  database; mirrors `/shared/admin2.html` (Today · cohort · roster + drawer ·
  messages · handed in) and adds the **Feedback board** tab (meters with
  distribution and trend, a computed reading, comments as cards, anonymous by
  default, notes kept in localStorage). The "sign-in" screen accepts anything.
- **`board.html`** — the feedback board on the room screen (`?w=N`), curtain +
  Reveal, never a name; keys ←/→, space, Esc.
- **`exam.html`** — a suggested final: 20 MCQ + 3 calculations marked on submit
  (±1 %), one Rhône Cement memo with a rubric; 90-min clock; `demo_exam` in
  localStorage; ⌥R clears the attempt. Numbers verified in Python (header).
- **`data.js`** is GENERATED by `_build/make-data.py` (seeded): twenty invented
  students, frozen on Tue 8 Sep 2026 09:00; six have no hand-in, three are
  "gone quiet", two never started, three messages wait; week 5 is the feedback
  low point. Re-run the script after changing it; never hand-edit data.js.
- Nobody in the dataset is real. The names are invented combinations.
