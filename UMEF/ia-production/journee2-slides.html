Ce qui ne va pas dans le serveur de vendredi

Il réentraîne votre modèle à chaque démarrage : il lit 24 000 opérations, entraîne, puis seulement répond.

  • Le démarrage est lent : c’était duree_demarrage_s dans GET /.
  • Deux démarrages peuvent donner deux modèles différents, sans que personne le sache.
  • Personne ne peut dire quel modèle répond : il n’a pas de nom.

La règle : on entraîne une fois, on enregistre le modèle dans un fichier qui porte une version, le service charge ce fichier. Ce fichier est un artefact.

Étape 4À retenir

Ce qu’il faut retenir

  • Charger un fichier prend quelques millisecondes ; entraîner prend des secondes. Le serveur de vendredi payait cela à chaque démarrage.
  • La forêt pèse 4 Mo (cent arbres) ; la régression logistique, 2 ko.
  • L’écart entre le modèle rechargé et le modèle en mémoire est exactement 0 : le fichier est le modèle.
  • L’empreinte change dès qu’un octet change : deux fichiers de même empreinte sont le même modèle.

2.3À retenir

Le versionnage sémantique, en trois lignes

  • Majeure (2.0.0) : les entrées changent ; le système qui appelle doit s’adapter.
  • Mineure (1.1.0) : un nouveau modèle, les mêmes entrées.
  • Correctif (1.0.1) : une erreur réparée, rien d’autre.

La pire option : remplacer le fichier sans changer la version. Deux modèles différents porteraient le même nom.

MIA 506 · Journée 229 / 45
2.3À retenir

Une limite de ce matin

Votre registre est un fichier à côté du modèle, et c’est vous qui l’avez écrit.

En entreprise, le registre est un service à part, avec des droits : un data scientist enregistre une version, une autre personne la promeut, le serveur de production ne lit que les versions promues.

Votre fichier montre les pièces ; il ne montre pas les droits.

2.4À vous

Jàppo Pay, les mêmes chiffres que vendredi

  • 1 800 000 opérations par jour = 54 000 000 par mois ; 50 par seconde à la pointe.
  • 20 millisecondes de processeur par prédiction ; 0,5 gibioctet de mémoire pendant un appel.
  • Aucune machine à plus de 50 % d’occupation à la pointe.
  • La limite de crédit : 400 000 clients, 5 ms chacun, une fois par nuit.

Faites les sept calculs à la main sur la page, puis vérifiez chacun.

MIA 506 · Journée 234 / 45
2.4À retenir

Ce qu’il faut retenir

  • Le paiement à l’appel gagne quand le trafic est faible ou irrégulier ; la machine louée gagne au-dessus d’un volume : ici 24 millions d’appels par mois.
  • Dans l’option B, le simple comptage des appels (0,40 $ le million) coûte autant que toute la machine A.
  • Le même modèle, par lots la nuit, coûte 42 fois moins qu’en temps réel : personne n’attend.
  • Le calculateur de la page : changez le volume et les millisecondes, regardez quelle option gagne.
