Étape 4

Pourquoi découper par date, et pas au hasard

  • Une fois en service, le modèle prévoit des jours à venir à partir de jours passés.
  • Le test doit ressembler à cet usage : le modèle est jugé sur des jours qu’il n’a pas vus.
  • Un découpage au hasard mettrait des opérations du 28 octobre dans l’entraînement.
  • Le modèle aurait alors déjà vu la fin du mois, et son résultat serait trop flatteur.

def preparer(d):
    d = d.copy()
    d["date_heure"] = pd.to_datetime(d["date_heure"])
    X = pd.DataFrame(index=d.index)
    X["montant_fcfa"] = d["montant_fcfa"]
    X["nouvel_appareil"] = d["nouvel_appareil"]
    X["nouveau_beneficiaire"] = d["nouveau_beneficiaire"]
    X["nb_operations_24h"] = d["nb_operations_24h"]
    X["anciennete_compte_jours"] = d["anciennete_compte_jours"]
    X["nuit"] = (d["date_heure"].dt.hour < 6).astype(int)
    X["part_du_solde"] = (d["montant_fcfa"] / d["solde_avant_fcfa"].clip(lower=1)).clip(upper=5)
    X["est_envoi"] = (d["type_operation"] == "envoi").astype(int)
    X["est_retrait"] = (d["type_operation"] == "retrait").astype(int)
    return X

Le seuil : à partir de quelle probabilité le modèle bloque

  • Le modèle donne à chaque opération une probabilité de fraude, entre 0 et 1.
  • Le seuil est la probabilité à partir de laquelle on bloque l’opération.
  • Au seuil de 0,5 : une opération dont la probabilité vaut 0,5 ou plus est bloquée.
  • Le modèle fait deux sortes d’erreurs : une fraude sous le seuil passe ; une opération honnête au-dessus du seuil est bloquée à tort.

def predire(operation):
    manquants = [c for c in VARIABLES_BRUTES if c not in operation]
    if manquants:
        return {"erreur": "champs manquants : " + ", ".join(manquants)}
    X = preparer(pd.DataFrame([operation]))
    p = float(modele.predict_proba(X)[0, 1])
    return {"probabilite_fraude": round(p, 3),
            "decision": "bloquer" if p >= SEUIL_FINAL else "accepter"}

TYPES_CONNUS = {"envoi", "paiement_marchand", "retrait", "depot"}

def predire(operation):
    manquants = [c for c in VARIABLES_BRUTES if c not in operation]
    if manquants:
        return {"erreur": "champs manquants : " + ", ".join(manquants)}
    for c in ["montant_fcfa", "solde_avant_fcfa", "anciennete_compte_jours", "nb_operations_24h"]:
        v = operation[c]
        if isinstance(v, bool) or not isinstance(v, (int, float)) or v < 0:
            return {"erreur": c + " doit être un nombre positif ; reçu : " + repr(v)}
    if operation["type_operation"] not in TYPES_CONNUS:
        return {"erreur": "type_operation inconnu : " + repr(operation["type_operation"])}
    if operation["montant_fcfa"] < 200:      # le plus petit montant des données est 200 FCFA
        return {"erreur": "montant_fcfa inférieur à 200 FCFA : vérifiez l'unité"}
    p = float(modele.predict_proba(preparer(pd.DataFrame([operation])))[0, 1])
    return {"probabilite_fraude": round(p, 3),
            "decision": "bloquer" if p >= SEUIL_FINAL else "accepter"}
