Construire un programme qui marche — un jeu, une appli, une page — en une après-midi

Ce que nous faisons aujourd’hui. Par équipes de deux, vous construisez un programme : un jeu, une petite application, ou la page dont votre projet a besoin. Vous ne tapez pas le code : vous le décrivez à une IA, qui l’écrit. Vous le collez dans le bac à sable de cette page, il tourne sous vos yeux, et la page vous dit ce qui manque. À 16h10, chaque programme est en ligne, à une adresse que toute la classe ouvre sur son téléphone, et la classe vote.

Pourquoi c’est intéressant pour vous. Un programme est un fichier texte. Depuis 2024, une IA écrit ce fichier à partir d’une description en français, en trente secondes. Ce qui compte n’est plus de savoir taper le code : c’est de décrire exactement ce que le programme doit faire, de le lancer, de lire ce qui ne va pas, et de le faire corriger. C’est ce que vous apprenez aujourd’hui, en construisant quelque chose que vous garderez.

Section 6.0 · Exercice réel

Le défi, les règles, l’équipe

Ce qu’est un programme — en trois phrases

Un programme est un fichier texte que le navigateur lit et exécute. Le fichier d’aujourd’hui s’appelle index.html et contient trois langages, qui se partagent le travail :

HTML
La structure
Ce qu’il y a sur la page : un titre, un bouton, une liste, une case à remplir. Entre des balises : <button>Clique</button>.
CSS
L’apparence
Les couleurs, les tailles, la place de chaque chose, et ce qui change sur un petit écran.
JavaScript
Le comportement
Ce qui se passe quand on clique, quand le temps passe, quand on tape : compter les points, afficher un message, garder le record.

L’IA écrit les trois à partir de votre description. Le navigateur les lit et affiche la page. Vous décidez ce que le programme doit faire, vous le lancez, et vous jugez si c’est fait. L’IA n’a pas de navigateur : elle ne voit jamais son programme tourner. C’est vous qui le voyez — et qui lui rapportez ce qui ne va pas.

Essayez ici · 1 · choisissez votre défi
  1. Lisez les six défis ci-dessous avec votre binôme. Chacun dit ce que l’utilisateur voit, ce qui se passe quand il agit, et ce que veut dire « ça marche » — c’est ce que le voisin testera en 6.2.
  2. Cliquez sur votre défi. Si votre projet a besoin d’un écran (une page de réservation, un calculateur, un formulaire), prenez Votre projet : vous construisez cet écran, et c’est votre version 1.
  3. Écrivez le carnet : vos deux prénoms, le défi, et une phrase qui dit ce que l’utilisateur fait et ce qui se passe.
Les règles du build-a-thon
Règle 1
Un seul fichier
Tout le programme tient dans index.html. Aucune bibliothèque téléchargée depuis internet : le fichier marche sans connexion, et on peut le lire en entier.
Règle 2
Des données inventées
🔐 Aucun vrai nom, numéro, e-mail ou prix de vraie personne dans le programme : à 16h10 il sera public, et tout ce qu’il contient sera lisible par n’importe qui. Inventez des prénoms et des numéros.
Règle 3
L’IA écrit, vous jugez
Vous pouvez corriger une ligne à la main, mais vous n’êtes pas obligés : l’IA corrige si vous lui donnez l’erreur exacte. Compter vos tours est normal — un programmeur en fait dix par heure.
Le jury
Cinq critères, 0 à 2 points
Ça marche sans erreur · on comprend sans explication · ça fait ce que le défi demande · ça tient sur un téléphone · une chose que personne n’a demandée.
Votre carnet · l’équipe et le défi
1.Vos deux prénoms · le défi · en une phrase : ce que l’utilisateur fait, et ce qui se passe.
Section 6.1 · Exercice réel

Le bac à sable : lancer un programme, lire l’erreur, la faire corriger

Essayez ici · le bac à sable
  1. Lancez le programme de départ (bouton ▶ Lancer). C’est un jeu : combien de clics en dix secondes ? Il contient une erreur, mise là exprès.
  2. Lisez la zone rouge sous l’aperçu : c’est le message exact du navigateur, avec le numéro de la ligne. Bouton Copier l’erreur pour l’IA : la page prépare un message qui contient l’erreur et tout le code.
  3. Collez-le dans votre assistant, et demandez le fichier corrigé en entier. Copiez sa réponse (le bouton « copier » du bloc de code), remplacez tout le contenu de la case de gauche (Ctrl+A puis Ctrl+V), et relancez.
  4. Jouez. Quand le jeu compte vos clics, la zone rouge est vide et la case « corrigé » se coche. Vous venez de faire la boucle de la journée : lancer → lire → donner à l’IA → relancer.
Essayez ici · 2 · qui fait quoi ?

Huit choses qui se passent quand le jeu tourne. Pour chacune : qui s’en charge — l’HTML, le CSS, le JavaScript, le navigateur, l’IA, ou vous ? Un seul bon choix par ligne ; la raison s’affiche.

    Si ça bloque
    
L’assistant explique, pose des questions, mais ne donne pas de code.
Répondez : « Ne pose pas de question. Donne le fichier complet, de <!doctype html> à </html>, et rien d’autre. »

    
Le code s’arrête au milieu, la fin manque.
La réponse était trop longue pour l’assistant. Demandez : « Renvoie le fichier en entier, plus court : pas de commentaires, pas d’explications. » Vérifiez que le code se termine par </html>.

    
L’aperçu est vide ou blanc, et la zone rouge est vide aussi.
Vous avez collé l’explication de l’assistant au lieu du code, ou seulement une partie. La case de gauche doit commencer par <!doctype html>. Ctrl+A, puis collez le bloc de code en entier.

    
Ça marche dans l’aperçu de l’assistant, pas ici — le contrôle « hors ligne » est rouge.
L’assistant a ajouté une bibliothèque depuis internet (une ligne <script src="https://…"> ou <link href="https://…">). Demandez : « Sans aucune bibliothèque externe : tout le CSS et tout le JavaScript dans le fichier. »

    
Erreur « … is not defined » ou « Cannot read properties of null ».
Un nom a changé entre deux versions, ou le script cherche un bouton qui n’existe pas encore. Bouton Copier l’erreur pour l’IA, collez, et demandez le fichier complet corrigé. Ne corrigez pas deux erreurs à la fois.

    
J’ai demandé un petit changement et l’assistant a tout refait différemment.
Demandez toujours : « Ne change que ceci. Garde tout le reste exactement identique, et renvoie le fichier complet. » Si c’est trop tard, collez votre bonne version dans l’assistant et dites : « Repars de ce fichier. »

    
Sur le téléphone, tout est minuscule ou déborde.
Il manque la balise <meta name="viewport"…> (le contrôle « téléphone » le dit), ou les tailles sont fixes. Demandez : « Ajoute la balise viewport et fais tenir la page sur 390 pixels de large, sans défilement horizontal. »

  1. Téléchargez le fichier : bouton ⬇ Télécharger index.html dans le bac à sable (il est en 6.3). Le fichier arrive dans Téléchargements. Créez un dossier mon-site et mettez index.html dedans, seul.
    2. 
      
  2. Ouvrez app.netlify.com/drop ↗ (connecté·e à votre compte Netlify). Glissez le dossier mon-site sur la zone « Drag and drop your site folder here ».
    3. 
      
  3. Après dix secondes, Netlify affiche une adresse comme https://glowing-tartufo-1a2b3c.netlify.app. Cliquez dessus : votre programme s’ouvre. Copiez l’adresse dans la case ci-dessous.
    4. 
      
  4. Envoyez-vous l’adresse sur WhatsApp et ouvrez-la sur votre téléphone. Jouez. Écrivez dans le carnet ce que vous voyez de différent par rapport à l’ordinateur.
    5. 
    

    

      
L’adresse de votre programme

      

        
🌐Collez l’adresse https://… que Netlify vous a donnée.

        
        

      

    

    
🔐 Ce qui vient de se passer. Votre fichier est copié sur un serveur de Netlify, et l’adresse pointe vers cette copie. N’importe qui, dans le monde, qui a l’adresse peut ouvrir la page — et lire le fichier en entier, y compris les commentaires et les données dedans. C’est pour cela que la règle 2 interdit les vraies données. Pour changer la page, vous glissez un nouveau dossier sur le même site (onglet Deploys) ; l’adresse reste la même.

  


  

    Si ça bloque
    
Netlify demande de se connecter ou de créer un compte.
« Sign up with Google », avec votre compte Google de l’école ou personnel. Une minute. Un site publié sans compte est effacé au bout d’une heure.

    
La page publiée est vide, ou dit « Page not found ».
Le fichier ne s’appelle pas exactement index.html (par exemple index (1).html ou index.html.txt), ou il n’est pas seul dans le dossier glissé. Renommez-le, remettez-le seul dans mon-site, glissez à nouveau.

    
Pas de compte possible, pas d’internet sur le téléphone.
Envoyez le fichier index.html à votre binôme sur WhatsApp : sur un ordinateur, double-cliquer le fichier l’ouvre dans le navigateur. Pour le vote, le prof ouvrira votre fichier sur l’écran.
