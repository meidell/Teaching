What we do today. In teams of two, you build a program: a game, a small application, or the page your project needs. You do not type the code: you describe it to an AI, which writes it. Section 6.0 · Real exercise

The challenge, the rules, the team

What a program is — in three sentences

A program is a text file that the browser reads and executes. Today’s file is called index.html and contains three languages, which share the work:

HTML
The structure
What is on the page: a title, a button, a list, a box to fill in. Between tags: <button>Click</button>.
CSS
The look
Colours, sizes, where each thing sits, and what changes on a small screen.
JavaScript
The behaviour
What happens when you click, when time passes, when you type: counting points, showing a message, keeping the record.

The AI writes all three from your description. The browser reads them and shows the page. You decide what the program must do, you run it, and you judge whether it is done. The AI has no browser: it never sees its program run. You are the one who sees it — and who reports to it what is wrong.

Try it here · 1 · choose your challenge
  1. Read the six challenges below with your partner. Each says what the user sees, what happens when they act, and what “it works” means — that is what the neighbour will test in 6.2.
  2. Click your challenge. If your project needs a screen (a booking page, a calculator, a form), take Your project: you build that screen, and it is your version 1.
  3. Write the notebook: your two first names, the challenge, and one sentence that says what the user does and what happens.
The rules of the build-a-thon
Rule 1
One single file
The whole program fits in index.html. No library downloaded from the internet: the file works without a connection, and can be read in full.
Rule 2
Made-up data
🔐 No real name, number, e-mail or price of a real person in the program: at 16:10 it will be public, and everything in it will be readable by anyone. Invent first names and numbers.
Rule 3
The AI writes, you judge
You may fix a line by hand, but you do not have to: the AI fixes it if you give it the exact error. Counting your rounds is normal — a programmer does ten an hour.
The jury
Five criteria, 0 to 2 points
It works without an error · you understand it without an explanation · it does what the challenge asks · it fits on a phone · one thing nobody asked for.

Section 6.1 · Real exercise

The sandbox: run a program, read the error, get it fixed

Try it here · the sandbox
  1. Run the starting program (button ▶ Run). It is a game: how many clicks in ten seconds? It contains one error, placed there on purpose.
  2. Read the red zone under the preview: it is the browser’s exact message, with the line number. Button Copy the error for the AI: the page prepares a message that contains the error and the whole code.
  3. Paste it into your assistant, and ask for the whole corrected file. Copy its answer (the “copy” button of the code block), replace all the content of the left box (Ctrl+A then Ctrl+V), and run again.
  4. Play. When the game counts your clicks, the red zone is empty and the “fixed” box ticks. You have just done the loop of the day: run → read → give to the AI → run again.

    If it blocks
    
The assistant explains, asks questions, but gives no code.
Answer: “Do not ask questions. Give the complete file, from <!doctype html> to </html>, and nothing else.”

    
The code stops in the middle, the end is missing.
The answer was too long for the assistant. Ask: “Send the whole file again, shorter: no comments, no explanations.” Check that the code ends with </html>.

    
The preview is empty or white, and the red zone is empty too.
You pasted the assistant’s explanation instead of the code, or only a part. The left box must start with <!doctype html>. Ctrl+A, then paste the whole code block.

    
It works in the assistant’s preview, not here — the “offline” check is red.
The assistant added a library from the internet (a line <script src="https://…"> or <link href="https://…">). Ask: “Without any external library: all the CSS and all the JavaScript inside the file.”

    
Error “… is not defined” or “Cannot read properties of null”.
A name changed between two versions, or the script looks for a button that does not exist yet. Button Copy the error for the AI, paste, and ask for the complete corrected file. Do not fix two errors at once.

    
I asked for a small change and the assistant redid everything differently.
Always ask: “Change only this. Keep everything else exactly the same, and send the complete file.” If it is too late, paste your good version into the assistant and say: “Start again from this file.”

    
On the phone, everything is tiny or overflows.
The <meta name="viewport"…> tag is missing (the “phone” check says so), or the sizes are fixed. Ask: “Add the viewport tag and make the page fit 390 pixels wide, without horizontal scrolling.”
