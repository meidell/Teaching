Séance 5 · mardi 10 novembre 2026 · 13h30–16h45 · GEN 110

Un agent qui cherche des offres chaque jour — et prépare la candidature en un clic

Ce que nous construisons aujourd’hui. Un vrai programme qui tourne sans vous. Chaque matin, il lit une liste de pages web que vous avez choisies, garde les offres qui contiennent vos mots-clés, et vous envoie la liste par e-mail. Dans cet e-mail, un clic sur « Préparer » fait écrire par Gemini un message et un CV adaptés à l’offre, que le programme dépose en brouillon dans votre Gmail, avec le CV en PDF. Un deuxième clic l’envoie.

Avec quoi. Des outils gratuits de votre compte Google : une Google Sheet (la liste des pages et des mots-clés, les offres trouvées), Google Apps Script (le programme, qui vit dans la feuille), Gmail, et l’API de Gemini (une clé gratuite). Le code est fourni et commenté : vous ne l’écrivez pas, vous le lisez, le réglez, le lancez et le réparez. C’est ainsi que l’on construit un agent en entreprise : des sources, un filtre, une action, une personne qui valide.

🏫 3 h 15 en deux blocs · ordinateur · un compte Google 🧰 Google Sheets · Apps Script · Gmail · une clé Gemini (gratuite)

Section 5.1 · Pièces 1 et 2 · Sources et filtre

Quelles pages lire, quels mots chercher — testés sur ce que voit le robot

Essayez ici · 0 · trouver vos sources avec une IA

Le programme ne lit que les pages que vous lui donnez. Il vous faut donc d’abord une liste de pages où les offres de votre domaine sont publiées en Suisse romande : des sites d’offres d’emploi, les pages Carrières d’entreprises de la région, des flux RSS. Une IA avec recherche sur le web vous propose cette liste en une minute. Elle peut aussi inventer une adresse qui n’existe pas : vous vérifiez donc chaque page avant de la garder.

  1. Décrivez ce que vous cherchez dans les deux cases ci-dessous : le type de poste et le domaine (« stage en marketing digital »), puis la région. La consigne se remplit toute seule.
  2. Copiez la consigne et collez-la dans Gemini ↗, ou dans ChatGPT avec la recherche web activée (bouton Rechercher sous la case de message). Sans recherche web, l’IA répond de mémoire et ses adresses sont souvent fausses.
  3. Ouvrez chaque adresse que l’IA propose, dans un nouvel onglet. Gardez-la seulement si la page s’ouvre et montre une liste d’offres. Une page d’accueil, une page d’erreur ou une page qui demande de se connecter ne sert à rien au programme.
  4. Collez les adresses gardées dans la case 1 du cadre suivant, une par ligne. La page vérifie chaque ligne et vous propose la bonne adresse quand vous avez collé la page d’accueil d’un site d’offres.

    

  


  

    Essayez ici · 1 et 2 · vos sources et vos mots-clés
    
    
      
  1. Les sources : dans la case 1, une adresse par ligne. Chaque adresse doit être celle d’une page qui liste des offres. Un flux RSS d’offres est le meilleur choix : il est fait pour être lu par un programme. La page signale les sites qui bloquent les robots.
    2. 
      
  2. Sur un site d’offres, collez l’adresse d’une recherche, pas celle de l’accueil. La page d’accueil de jobup.ch (https://www.jobup.ch/fr/) ne contient aucune offre : le robot y trouve zéro lien d’offre. Faites la recherche vous-même sur le site : tapez « stage marketing » dans la case de recherche, choisissez la ville, lancez la recherche. L’adresse de la page de résultats contient alors vos mots, par exemple https://www.jobup.ch/fr/emplois/?term=stage%20marketing&location=Genève. Copiez cette adresse depuis la barre d’adresse du navigateur et collez-la dans la case 1. Le robot y trouve une vingtaine d’offres, et il refait la même recherche chaque matin. Sur une adresse de recherche, le robot garde toutes les offres que le site a trouvées : le site a déjà fait le tri, vos mots-clés ne servent pas une deuxième fois. Seules vos exclusions (« -directeur ») écartent encore des offres. Pour deux recherches sur le même site (« stage marketing » et « stage communication »), mettez deux lignes.
    3. 
      
  3. Les mots-clés : dans la case 2, un par ligne. Plusieurs mots sur une ligne = tous doivent être présents (« stage marketing »). Un mot précédé de « - » exclut l’offre (« -directeur »).
    4. 
      
  4. Les mots-clés servent pour les autres pages : les pages Carrières et les flux RSS, où le robot ne garde que les offres dont le titre contient vos mots. Écrivez-les dans les deux langues des offres. En Suisse romande, beaucoup d’offres ont un titre en anglais : « Marketing Intern » ne contient pas le mot « stage ». Le robot ne garde que les offres dont le titre contient vos mots : mettez donc « stage marketing » et « marketing intern » sur deux lignes.
    5. 
    

    

      
      
    

    

    

  


  

    Votre carnet · la configuration
    
1.Vos sources et vos mots-clés, assemblés par la page. Modifiez les cases 1 et 2, pas ce texte.

      

  


  

    Essayez ici · 3 · ce que voit le robot
    
    
      
  1. Le test du robot : ouvrez une de vos pages, puis son code source — clic droit → Afficher le code source, ou Ctrl+U / ⌥⌘U. Sélectionnez tout, copiez, collez dans la case 3. La page fait exactement ce que fera le programme : elle lit tous les liens et garde ceux qui contiennent vos mots-clés.
    2. 
    

    

      
L’adresse de la page testée, puis son code source

      
      
      

      

    

    
Pourquoi ce test ? Le programme ne voit pas la page comme vous : il reçoit le code source, le texte que le serveur envoie, sans exécuter le JavaScript. Beaucoup de sites modernes envoient une page presque vide et remplissent les offres ensuite, avec du JavaScript : vous voyez quarante offres, le robot n’en voit aucune. Si le test trouve moins de cinq liens, cherchez un flux RSS du site, ou une autre page.

  


  


  

    
    
  







  
  
Section 5.2 · Pièce 3 · Le programme
La Google Sheet, le script, la première recherche, le réveil quotidien


  

    Essayez ici · le programme, à copier
    
    
      
  1. La feuille : sheets.new ↗ crée une Google Sheet vide. Nommez-la « Job agent ».
    2. 
      
  2. Le script : dans la feuille, menu Extensions → Apps Script. Un éditeur s’ouvre, nommé « Untitled project » (« Projet sans titre ») : c’est normal, chaque feuille a son propre projet, vide au départ, même si la feuille s’appelle « Job agent ». Il contient un fichier Code.gs qui contient déjà trois lignes : function myFunction() {, une ligne vide, }. Effacez ces trois lignes : cliquez dans l’éditeur, Ctrl+A (⌘A sur Mac), puis Suppr. L’éditeur doit être complètement vide. Puis bouton Copier le programme ci-dessous, collez, et Enregistrer (l’icône disquette). La première ligne du fichier doit maintenant être /* =====, et la dernière ligne function page_(html) …. Si votre programme est collé entre function myFunction() { et }, rien ne marche : pas de menu, pas d’onglets.
    3. 
      
  3. Première exécution : en haut de l’éditeur, à droite du bouton Exécuter, une liste montre le nom d’une fonction : elle doit montrer setup (c’est la première fonction du programme). Cliquez Exécuter. Quand c’est fini, la feuille affiche en bas à droite « Quatre onglets prêts ». Si la liste ne propose que myFunction, votre programme est collé à l’intérieur de myFunction : revenez à l’étape 2. Si le journal dit « Ce script n’est attaché à aucune feuille », vous avez ouvert Apps Script ailleurs que depuis la feuille : recommencez l’étape 2 depuis le menu Extensions de la feuille. Google demande une autorisation : Examiner les autorisations → votre compte → « Google n’a pas validé cette application » → Paramètres avancés → Accéder à Job agent (non sécurisé) → Autoriser. C’est votre propre programme : Google prévient parce que personne ne l’a vérifié.
    4. 
    

    

    

  


  

    Lire le programme — cinq fonctions, cinq métiers
    
    
      
  • crawl() va chercher : pour chaque URL, UrlFetchApp.fetch télécharge la page, comme un navigateur qui ne montrerait que le code source. Une réponse autre que 200 (403 : refusé ; 404 : introuvable) est notée dans le journal et la source est sautée.
    • 
      
  • extract_() découpe : dans un flux RSS, chaque <item> donne un titre et un lien ; dans une page web, chaque balise <a href> donne un lien et son texte.
    • 
      
  • match_() filtre : il enlève accents et majuscules, puis garde la ligne si tous les mots d’un mot-clé y sont, et qu’aucun mot exclu n’y est. C’est exactement ce qu’a fait le test du robot en 5.1.
    • 
      
  • seen se souvient : chaque lien déjà présent dans l’onglet Offres est ignoré. Sans cela, l’e-mail de demain répéterait celui d’aujourd’hui.
    • 
      
  • Logger.log('JOBAGENT …') rend compte : pages lues, erreurs, liens, nouvelles offres. Un agent qui travaille seul doit dire ce qu’il a fait ; le journal est la première chose qu’on lit quand il se tait.
    • 
    

  


  

    Votre carnet · le journal de la première recherche
    
    
      
  1. Remplissez la feuille : rechargez-la ; quatre onglets sont apparus (Sources, Mots-clés, Offres, Profil), et un menu 🤖 Job agent à droite du menu Aide. Le menu peut mettre une dizaine de secondes à apparaître. Rien après un rechargement ? Dans l’éditeur, Exécutions (l’icône ≡ à gauche) doit montrer une ligne setup terminée ; s’il n’y a que myFunction, reprenez l’étape 2. Collez vos URL dans Sources (cellule A2) et vos mots-clés dans Mots-clés (cellule A2) — les boutons de 5.1.
    2. 
      
  2. La recherche : menu 🤖 Job agent → 2 · Chercher maintenant. Regardez l’onglet Offres se remplir. Puis, dans l’éditeur, Exécutions (l’icône ≡ à gauche) → la dernière exécution : copiez la ligne qui commence par JOBAGENT et collez-la dans le carnet.
    3. 
      
  3. Le réveil : menu 🤖 Job agent → 4 · Activer la recherche chaque jour. Vérifiez dans l’éditeur, Déclencheurs (l’icône ⏰) : une ligne daily, « chaque jour, 7h–8h ».
    4. 
    

    
1.La ligne JOBAGENT de la dernière exécution, et les lignes ⚠ s’il y en a.

      

    

    

  


  


  

    
    
  







  
  
Section 5.3 · Bloc 2 · Pièce 4 · Le résumé
L’e-mail du matin, et l’adresse web qui recevra vos clics


  

    Votre carnet · l’adresse de l’application
    
    
      
  1. Publier : dans l’éditeur Apps Script, Déployer → Nouveau déploiement → roue dentée → Application Web. Exécuter en tant que : Moi. Qui a accès : Seulement moi. Déployer. Copiez l’URL de l’application Web (elle se termine par /exec) et collez-la dans le carnet. ⚠ L’application Web garde le code du moment où vous l’avez publiée. Chaque fois que vous changez le code ensuite, publiez une nouvelle version : Déployer → Gérer les déploiements → l’icône crayon → Version : Nouvelle version → Déployer. L’URL ne change pas. Sans cela, les liens Préparer et Envoyer lancent l’ancien code.
    2. 
      
  2. La ranger : dans l’éditeur, Paramètres du projet (la roue dentée à gauche) → Propriétés du script → Ajouter : nom WEBAPP_URL, valeur = cette URL. Enregistrer.
    3. 
      
  3. Le premier e-mail : pour avoir des offres « nouvelles », effacez les lignes 2 et suivantes de l’onglet Offres, puis menu 🤖 Job agent → 3 · Chercher et m’envoyer la liste. Ouvrez Gmail : un e-mail « Job agent · N nouvelle(s) offre(s) », un lien « ✉ Préparer » sur chaque ligne.
    4. 
    

    
1.L’URL de l’application Web (celle qui se termine par /exec).

      

    

    

  


  

    Pourquoi « Seulement moi » compte
    
Un lien « Préparer » ou « Envoyer » est une commande : quiconque l’ouvre déclenche l’action. Avec Seulement moi, Google n’exécute la commande que si la personne qui clique est connectée à votre compte ; un e-mail transféré par erreur ne permet à personne d’envoyer une candidature à votre place. Avec Tout le monde, le lien deviendrait une porte ouverte sur votre Gmail. Règle générale : une application qui agit en votre nom n’est accessible qu’à vous.

  


  


  

    
    
  







  
  
Section 5.4 · Pièce 5 · Les deux clics
Clic 1 : Gemini prépare. Clic 2 : vous envoyez.


  

    Essayez ici · 1 · votre profil, sans données personnelles
    
    
      
  1. La clé : aistudio.google.com/apikey ↗ → Create API key. Si la fenêtre dit No Cloud Projects Available, votre compte n’a pas encore de projet Google Cloud, et une clé se range toujours dans un projet : fermez la fenêtre (Cancel), cliquez Projects dans le menu de gauche, puis + Create project, nommez-le « Job agent », et revenez sur API keys → Create API key → choisissez « Job agent » dans la liste → Create key. Copiez la clé. Elle commence par AQ. (une clé créée avant fin mai 2026 commence par AIza : les deux formats marchent). Dans l’éditeur Apps Script, Paramètres du projet → Propriétés du script → Ajouter : nom GEMINI_API_KEY, valeur = la clé. 🔐 Nulle part ailleurs : ni dans la feuille, ni dans le code, ni dans un carnet de ce site.
    2. 
      
  2. Votre nom et votre contact, deux autres propriétés : MY_NAME (« Awa Ndiaye ») et MY_CONTACT (« awa@… · +41 … »). Le programme les écrit dans le message et le CV après la réponse de Gemini : Gemini ne les voit jamais.
    3. 
      
  3. Votre profil : remplissez les cases ci-dessous, Copier mon profil, et collez-le dans l’onglet Profil : cliquez la cellule A2, puis collez. Le texte se répartit sur les lignes 2, 3, 4… : c’est normal, le programme lit toute la colonne A à partir de A2.
    4. 
    

    

      

      

      

    

    
1.Le profil assemblé — à coller dans l’onglet Profil, cellule A2.

      

    

  


  

    La consigne que le programme donne à Gemini
    
C’est un modèle avec des variables : le programme remplace {{PROFILE}}, {{TITLE}}, {{LINK}} et {{OFFER}} par votre profil et par le texte de la page de l’offre, qu’il télécharge. Il demande une réponse en JSON — quatre champs nommés — parce qu’un programme lit un JSON sans se tromper, alors qu’il lirait mal un texte libre. {{NAME}} et {{CONTACT}} restent tels quels dans la réponse ; le programme les remplace ensuite, chez vous.

    

  


  

    Votre carnet · le premier brouillon
    
    
      
  1. Clic 1 : dans l’e-mail du matin, ✉ Préparer sur une offre. Une page s’ouvre après une vingtaine de secondes : l’objet, le message, ce que l’offre demande et que vous n’avez pas. Un brouillon est dans Gmail, avec le CV en PDF. Lisez les deux. Collez le message dans le carnet.
    2. 
      
  2. Clic 2 : J’ai relu — envoyer. En mode test (TEST_MODE: true, le réglage de départ), la candidature vous est envoyée à vous-même : vérifiez votre boîte. Vous ne passerez à false qu’après avoir relu plusieurs brouillons.
    3. 
    

    
1.L’objet et le message préparés par l’agent, tels qu’ils s’affichent après le clic 1.
