An agent that searches for offers every day — and prepares the application in one click

What we build today. A real program that runs without you. Every morning it reads a list of web pages you chose, keeps the offers that contain your keywords, and e-mails you the list. In that e-mail, one click on “Prepare” has Gemini write a message and a CV tailored to the offer, which the program drops as a draft into your Gmail, with the CV as a PDF. A second click sends it.

With what. Free tools in your Google account: a Google Sheet (the list of pages and keywords, the offers found), Google Apps Script (the program, which lives in the sheet), Gmail, and the Gemini API (a free key). The code is provided and commented: you do not write it, you read it, set it up, run it and fix it. That is how an agent is built in a company: sources, a filter, an action, a person who approves.

Section 5.1 · Pieces 1 and 2 · Sources and filter

Which pages to read, which words to look for — tested on what the robot sees

Try it here · 0 · finding your sources with an AI

The program only reads the pages you give it. So you first need a list of pages where offers in your field are published in French-speaking Switzerland: job sites, the Careers pages of companies in the region, RSS feeds. An AI with web search proposes this list in a minute. It can also invent an address that does not exist, so you check every page before keeping it.

  1. Describe what you are looking for in the two boxes below: the type of position and the field (“marketing internship”), then the region. The prompt fills itself in.
  2. Copy the prompt and paste it into Gemini ↗, or into ChatGPT with web search turned on (the Search button under the message box). Without web search the AI answers from memory, and its addresses are often wrong.
  3. Open every address the AI proposes, in a new tab. Keep it only if the page opens and shows a list of offers. A home page, an error page or a page that asks you to log in is useless to the program.
  4. Paste the addresses you kept into box 1 of the next box, one per line. The page checks every line and proposes the right address when you have pasted a job site’s home page.

    Reading the program — five functions, five jobs
    
    
      
  • crawl() fetches: for each URL, UrlFetchApp.fetch downloads the page, like a browser that would only show the source code. Any answer other than 200 (403: refused; 404: not found) is written to the log and the source is skipped.
    • 
      
  • extract_() cuts up: in an RSS feed, each <item> gives a title and a link; in a web page, each <a href> tag gives a link and its text.
    • 
      
  • match_() filters: it removes accents and capitals, then keeps the line if all the words of a keyword are there, and no excluded word is. It is exactly what the robot test did in 5.1.
    • 
      
  • seen remembers: every link already in the Offers tab is ignored. Without it, tomorrow’s e-mail would repeat today’s.
    • 
      
  • Logger.log('JOBAGENT …') reports: pages read, errors, links, new offers. An agent that works alone must say what it did; the log is the first thing you read when it goes quiet.
    •

    Why “Only myself” matters
    
A “Prepare” or “Send” link is a command: whoever opens it triggers the action. With Only myself, Google runs the command only if the person clicking is signed in to your account; an e-mail forwarded by mistake lets nobody send an application in your place. With Anyone, the link would become an open door to your Gmail. General rule: an app that acts in your name is reachable by you only.

    The instruction the program gives Gemini
    
It is a template with variables: the program replaces {{PROFILE}}, {{TITLE}}, {{LINK}} and {{OFFER}} with your profile and with the text of the offer’s page, which it downloads. It asks for an answer in JSON — four named fields — because a program reads JSON without mistakes, whereas it would misread free text. {{NAME}} and {{CONTACT}} stay as they are in the answer; the program replaces them afterwards, on your side.
