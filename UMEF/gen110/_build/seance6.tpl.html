⟦Ce que nous faisons aujourd’hui. Par équipes de deux, vous construisez un programme : un jeu, une petite application, ou la page dont votre projet a besoin. Vous ne tapez pas le code : vous le décrivez à une IA, qui l’écrit. Vous le collez dans le bac à sable de cette page, il tourne sous vos yeux, et la page vous dit ce qui manque. À 16h10, chaque programme est en ligne, à une adresse que toute la classe ouvre sur son téléphone, et la classe vote.⫽What we do today. In teams of two, you build a program: a game, a small application, or the page your project needs. You do not type the code: you describe it to an AI, which writes it. You paste it into this page’s sandbox, it runs in front of you, and the page tells you what is missing. At 16:10 every program is online, at an address the whole class opens on their phones, and the class votes.⟧

⟦Pourquoi c’est intéressant pour vous. Un programme est un fichier texte. Depuis 2024, une IA écrit ce fichier à partir d’une description en français, en trente secondes. Ce qui compte n’est plus de savoir taper le code : c’est de décrire exactement ce que le programme doit faire, de le lancer, de lire ce qui ne va pas, et de le faire corriger. C’est ce que vous apprenez aujourd’hui, en construisant quelque chose que vous garderez.⫽Why this matters to you. A program is a text file. Since 2024, an AI writes that file from a description in plain language, in thirty seconds. What matters is no longer being able to type the code: it is describing exactly what the program must do, running it, reading what is wrong, and getting it fixed. That is what you learn today, by building something you will keep.⟧

⟦Ce qu’est un programme — en trois phrases⫽What a program is — in three sentences⟧

⟦Un programme est un fichier texte que le navigateur lit et exécute. Le fichier d’aujourd’hui s’appelle index.html et contient trois langages, qui se partagent le travail :⫽A program is a text file that the browser reads and executes. Today’s file is called index.html and contains three languages, which share the work:⟧

HTML
⟦La structure⫽The structure⟧
⟦Ce qu’il y a sur la page : un titre, un bouton, une liste, une case à remplir. Entre des balises : <button>Clique</button>.⫽What is on the page: a title, a button, a list, a box to fill in. Between tags: <button>Click</button>.⟧
CSS
⟦L’apparence⫽The look⟧
⟦Les couleurs, les tailles, la place de chaque chose, et ce qui change sur un petit écran.⫽Colours, sizes, where each thing sits, and what changes on a small screen.⟧
JavaScript
⟦Le comportement⫽The behaviour⟧
⟦Ce qui se passe quand on clique, quand le temps passe, quand on tape : compter les points, afficher un message, garder le record.⫽What happens when you click, when time passes, when you type: counting points, showing a message, keeping the record.⟧

⟦L’IA écrit les trois à partir de votre description. Le navigateur les lit et affiche la page. Vous décidez ce que le programme doit faire, vous le lancez, et vous jugez si c’est fait. L’IA n’a pas de navigateur : elle ne voit jamais son programme tourner. C’est vous qui le voyez — et qui lui rapportez ce qui ne va pas.⫽The AI writes all three from your description. The browser reads them and shows the page. You decide what the program must do, you run it, and you judge whether it is done. The AI has no browser: it never sees its program run. You are the one who sees it — and who reports to it what is wrong.⟧
