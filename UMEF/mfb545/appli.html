Votre première appli : des cours en direct, sur votre téléphone

Votre projet est une application d’épargne. Derrière chaque appli financière il y a la même chose : le téléphone demande des données à un serveur (une API), puis les affiche. Dans cet atelier vous prenez une petite appli qui affiche le franc suisse en euros, en dollars et en francs CFA, et le prix du bitcoin. Vous la modifiez, vous la mettez en ligne, et vous l’installez sur votre téléphone, avec son icône.

Avant de commencer

Trois mots, et deux voies

API : une adresse Internet qu’un programme interroge pour recevoir des données, au lieu d’une page à lire. Exemple : api.frankfurter.dev/v1/latest?base=CHF répond avec les taux du jour de la Banque centrale européenne (BCE). Ouvrez ce lien ↗ : vous voyez la réponse brute.

JSON : le format de cette réponse, des noms et des valeurs entre accolades, que le programme lit facilement.

Application web installable : une page web avec un nom, une icône et un mode plein écran. Le téléphone l’installe sur l’écran d’accueil comme une appli, sans passer par l’App Store ou Google Play.

Voie A · tout le monde · environ 45 minutes

Une application web installable. Il suffit d’un ordinateur, même ancien, avec un navigateur, et d’un éditeur de texte : VS Code, ou à défaut le Bloc-notes. Rien d’autre à installer.

Voie B · si votre ordinateur le permet

La même appli en application native (React Native), lancée sur le téléphone avec l’appli Expo Go. Il faut installer Node.js (environ 100 Mo) et une bonne connexion. À faire après la voie A, ou à la maison.

Pourquoi pas Yahoo Finance ? Yahoo n’a pas d’API officielle. Le 14 novembre 2026, ses adresses ont répondu « trop de demandes » (code 429) à chacun de nos essais, et elles refusent les appels venant d’une page web. L’appli utilise donc deux sources gratuites, sans inscription et autorisées dans un navigateur : Frankfurter, qui publie les taux de référence de la BCE chaque jour ouvrable, et CoinGecko, qui publie les prix des cryptomonnaies. Pour des cours d’actions, il faut un fournisseur qui donne une clé gratuite (par exemple Alpha Vantage ou Twelve Data) ; une clé ne se met jamais dans le code d’une page publique.
Étape 0 · voir le résultat

Ouvrez l’appli finie sur votre téléphone

Scannez le code avec l’appareil photo du téléphone, ou ouvrez janerikmeidell.com/UMEF/mfb545/files/app/. Puis installez-la sur l’écran d’accueil :

iPhone : ouvrez le lien dans Safari. Appuyez sur le bouton Partager (le carré avec une flèche vers le haut), puis sur « Sur l’écran d’accueil », puis Ajouter.
Android : ouvrez le lien dans Chrome. Appuyez sur le menu ⋮ en haut à droite, puis sur « Installer l’application » ou « Ajouter à l’écran d’accueil ».

L’icône apparaît sur l’écran d’accueil. Ouverte depuis l’icône, l’appli occupe tout l’écran, sans barre d’adresse. C’est exactement ce que vous allez fabriquer.

Voie A · l’application web installable

Modifiez l’appli, mettez-la en ligne, installez-la

  1. Installez VS Code, l’éditeur de code gratuit de Microsoft, depuis code.visualstudio.com ↗. Si l’installation est refusée ou trop lente, ouvrez vscode.dev ↗ dans Chrome ou Edge : c’est le même éditeur, dans le navigateur, sans installation. En dernier recours, le Bloc-notes de Windows suffit.
  2. Téléchargez le kit mes-cours.zip ↓ (11 Ko). Clic droit sur le fichier → Extraire tout. Vous obtenez un dossier mes-cours avec quatre fichiers : index.html (l’appli), manifest.webmanifest (son nom et son icône) et deux images d’icône.
  3. Ouvrez le dossier dans VS Code : menu Fichier → Ouvrir le dossier → choisissez mes-cours. Cliquez sur index.html à gauche. Le fichier a trois parties, marquées par des commentaires : 1. vos réglages, 2. les sources de données, 3. le programme.
  4. Lancez l’appli sur l’ordinateur : dans l’explorateur de fichiers, double-cliquez sur index.html. Elle s’ouvre dans le navigateur et affiche les cours. Gardez cette fenêtre ouverte à côté de VS Code.
  5. Changez les réglages. Dans la partie 1, ajoutez le yen et le dollar canadien, et la cryptomonnaie solana. Les lignes deviennent : 
    const DEVISES = ["EUR", "USD", "GBP", "JPY", "CAD"];
const CRYPTOS = ["bitcoin", "ethereum", "solana"];
    Enregistrez (Ctrl + S, ou Cmd + S sur Mac), puis rechargez la page du navigateur (F5). Les nouvelles lignes apparaissent. Si une ligne affiche « nom inconnu chez CoinGecko », le nom est mal écrit : cherchez le bon nom sur coingecko.com, il est dans l’adresse de la page de la monnaie.
  6. Changez l’apparence : dans la partie <style>, remplacez la couleur #176B87 par une autre (par exemple #1b7f4b, un vert), et le titre « Mes cours » dans <h1> par le nom de votre appli. Enregistrez, rechargez.
  7. Mettez l’appli en ligne avec Netlify Drop, comme pour votre plan de la journée 5 : ouvrez app.netlify.com/drop ↗ et glissez le dossier mes-cours entier dans la zone. Netlify vous donne une adresse du type quelque-chose.netlify.app. Créez un compte gratuit (avec Google, c’est le plus rapide) pour que le site reste en ligne.
  8. Installez-la sur votre téléphone : ouvrez votre adresse .netlify.app sur le téléphone, puis suivez les instructions iPhone ou Android de l’étape 0. Votre icône est sur l’écran d’accueil, avec vos devises et votre couleur.
L’adresse de votre appli en ligne

Collez l’adresse que Netlify vous a donnée (elle commence par https://). L’enseignant la voit, et l’étape « votre première appli » de la journée 6 est cochée.

Ça ne marche pas ? Les trois problèmes les plus fréquents
  • « Chargement… » ne disparaît pas : appuyez sur F12 dans le navigateur, onglet Console. L’erreur en rouge indique la ligne. Le plus souvent : une virgule ou un guillemet oublié dans une liste.
  • Pas de « Installer l’application » sur Android : l’adresse doit commencer par https:// (c’est le cas sur Netlify) et le fichier manifest.webmanifest doit être dans le même dossier que index.html.
  • Sur iPhone, l’icône est une capture d’écran : vérifiez que icon-192.png est bien dans le dossier envoyé à Netlify.
Défis · pour celles et ceux qui ont fini

Rapprochez l’appli de votre projet

Vous pouvez demander l’aide d’une IA (Claude, ChatGPT) : collez index.html et décrivez ce que vous voulez. Lisez ensuite ce qui a changé, et sachez l’expliquer : c’est votre appli.

  1. Un convertisseur : ajoutez une case où l’on tape un montant en francs suisses, et affichez sa valeur en francs CFA. Indice : un <input type="number"> et le taux EUR multiplié par 655,957.
  2. Les couleurs de la variation : affichez la variation sur 24 heures en vert quand elle est positive et en rouge quand elle est négative.
  3. Le lien avec votre projet : votre client verse 10 000 FCFA par mois dans des fonds suisses en francs. Affichez combien de francs suisses cela fait aujourd’hui, et dites dans une phrase pourquoi ce montant change d’un mois à l’autre alors que le franc CFA est fixé à l’euro.
Voie B · une application native avec Expo

La même appli en React Native, lancée dans Expo Go

React Native est la technique utilisée par beaucoup d’applis bancaires : on écrit en JavaScript, et l’appli utilise les vrais composants de l’iPhone ou de l’Android. Expo Go est une appli gratuite qui fait tourner votre code sur le téléphone pendant que vous le développez, sans compte développeur.

  1. Installez Node.js, version « LTS », depuis nodejs.org ↗. Acceptez les options par défaut.
  2. Installez Expo Go sur le téléphone, depuis l’App Store ou Google Play.
  3. Dans VS Code, ouvrez un terminal (menu Terminal → Nouveau terminal) et tapez, ligne par ligne : 
    npx create-expo-app@latest mes-cours-natif --template blank
cd mes-cours-natif
    La première commande télécharge environ 200 Mo : il faut une bonne connexion et quelques minutes.
  4. Ouvrez le dossier mes-cours-natif dans VS Code, ouvrez App.js, effacez tout, et collez ce code : 
    import { useEffect, useState } from "react";
import { SafeAreaView, ScrollView, Text, View, Pressable, StyleSheet } from "react-native";

// 1. Vos réglages
const DEVISES = ["EUR", "USD", "GBP"];
const CRYPTOS = ["bitcoin", "ethereum"];
const FCFA_PAR_EURO = 655.957; // parité fixe : 1 euro = 655,957 francs CFA

export default function App() {
  const [taux, setTaux] = useState(null);
  const [cryptos, setCryptos] = useState(null);
  const [message, setMessage] = useState("Chargement…");

  // 2. Demander les données aux deux API
  async function charger() {
    setMessage("Chargement…");
    try {
      const a = await fetch("https://api.frankfurter.dev/v1/latest?base=CHF&symbols=" + DEVISES.join(","));
      const b = await fetch("https://api.coingecko.com/api/v3/simple/price?vs_currencies=chf&ids=" + CRYPTOS.join(","));
      setTaux(await a.json());
      setCryptos(await b.json());
      setMessage("Mis à jour à " + new Date().toLocaleTimeString());
    } catch (e) {
      setMessage("Pas de réponse du serveur : " + e.message);
    }
  }
  useEffect(() => { charger(); }, []);

  // 3. Afficher
  return (
    <SafeAreaView style={s.page}>
      <ScrollView contentContainerStyle={{ padding: 16 }}>
        <Text style={s.titre}>Mes cours</Text>
        <Text style={s.section}>1 franc suisse vaut</Text>
        {taux && DEVISES.map((c) => (
          <View key={c} style={s.ligne}><Text style={s.nom}>{c}</Text><Text style={s.prix}>{taux.rates[c].toFixed(4)}</Text></View>
        ))}
        {taux && taux.rates.EUR && (
          <View style={s.ligne}><Text style={s.nom}>FCFA</Text><Text style={s.prix}>{(taux.rates.EUR * FCFA_PAR_EURO).toFixed(2)}</Text></View>
        )}
        <Text style={s.section}>Cryptomonnaies, en francs suisses</Text>
        {cryptos && CRYPTOS.map((id) => (
          <View key={id} style={s.ligne}><Text style={s.nom}>{id}</Text><Text style={s.prix}>{cryptos[id] ? cryptos[id].chf.toFixed(2) : "—"}</Text></View>
        ))}
        <Pressable style={s.bouton} onPress={charger}><Text style={s.boutonTexte}>Actualiser les cours</Text></Pressable>
        <Text style={s.info}>{message}</Text>
      </ScrollView>
    </SafeAreaView>
  );
}

const s = StyleSheet.create({
  page: { flex: 1, backgroundColor: "#f2f6f8" },
  titre: { fontSize: 28, fontWeight: "bold", color: "#176B87", marginTop: 20 },
  section: { fontSize: 13, color: "#176B87", marginTop: 20, marginBottom: 6, textTransform: "uppercase" },
  ligne: { flexDirection: "row", justifyContent: "space-between", backgroundColor: "white", padding: 14, borderRadius: 12, marginBottom: 8 },
  nom: { fontSize: 16, fontWeight: "bold" },
  prix: { fontSize: 18, fontWeight: "bold" },
  bouton: { backgroundColor: "#176B87", padding: 15, borderRadius: 12, marginTop: 14 },
  boutonTexte: { color: "white", fontSize: 17, fontWeight: "bold", textAlign: "center" },
  info: { textAlign: "center", color: "#6b8590", marginTop: 10 },
});
  5. Enregistrez, puis dans le terminal tapez npx expo start. Un code QR s’affiche dans le terminal.
  6. Scannez-le : sur Android, avec le bouton « Scan QR code » de l’appli Expo Go ; sur iPhone, avec l’appareil photo. L’appli s’ouvre sur le téléphone. Chaque fois que vous enregistrez App.js, elle se met à jour toute seule.
  7. Si le téléphone ne trouve pas l’ordinateur (le Wi-Fi de l’école bloque souvent les appareils entre eux), arrêtez avec Ctrl + C et relancez avec npx expo start --tunnel. Acceptez l’installation qu’il propose.
Et pour publier dans l’App Store ou Google Play ? Il faut un compte développeur : chez Apple, l’Apple Developer Program coûte 99 dollars par an ; chez Google, l’inscription à la Play Console coûte 25 dollars, une fois. Puis chaque version passe une vérification par Apple ou Google, qui peut prendre plusieurs jours. Pour une appli financière, les deux magasins demandent aussi de montrer que l’entreprise a les autorisations nécessaires dans chaque pays où l’appli est proposée. C’est une raison de plus pour laquelle beaucoup de fintechs commencent par une application web.
