Les cours de Jan Erik Meidell

Chaque cours a ici son site : les séances une par une, les exercices qui se corrigent sur la page, les quiz, un fil de messages avec l’enseignant. Votre travail est enregistré et vous suit d’un appareil à l’autre.

Connectez-vous une fois avec votre nom et un mot de passe de votre choix : la connexion vaut pour tous les cours de cette page sur cet appareil. Les informations officielles — horaires, inscriptions, examens — restent sur la plateforme de l’école.

Comment ces cours fonctionnent

Peu d’exposé, beaucoup d’atelier : chaque séance alterne des exposés courts, écrits en entier sur la page pour pouvoir les relire seul·e, et des ateliers où vous travaillez — écritures comptables vérifiées une à une, jeux de rôle, simulateurs, feuilles de calcul interactives. Les quiz se lancent en classe, pour tout le monde en même temps. Un seul cas d’entreprise traverse souvent tout le cours, pour que chaque séance reprenne les chiffres de la précédente.
